FAQ

Questions

What does it cost?

Nothing beyond the Claude Code you already use. GitHub Pages hosting is free for public repositories.

Do I need to code?

No. You describe the site and ask for changes in plain words. Claude writes the code and runs the publishing script.

How does it get access to my GitHub?

The script uses credentials already on your machine: the GitHub CLI, a GITHUB_TOKEN variable, or the git credential manager. It never prints them and only talks to GitHub.

Can it overwrite something by accident?

No. It refuses to touch an existing repository unless you explicitly ask for an update, and it refuses folders whose git remote points somewhere else.

What kinds of sites?

Static sites: landing pages, portfolios, event pages, menus, resumes. No server code or user accounts, because that's how GitHub Pages works.

Can I use my own domain?

Yes. Ask for it, and the script sets up the domain on GitHub and tells you exactly which DNS records to add.

Can the sites have motion design?

Yes. With the companion motion-site skill installed, ask for "motion" and the site gets scroll scenes, masked text reveals, and a frame-by-frame review.
